# Referencias — UBL 2.1

Carpeta de solo lectura para los esquemas OASIS UBL 2.1.

## Archivos incorporados (2026-11-06)

Descargados sin modificar desde la distribución oficial `os-UBL-2.1` de OASIS. Incluyen los documentos principales (`UBL-Invoice-2.1.xsd`, `UBL-CreditNote-2.1.xsd`, `UBL-DebitNote-2.1.xsd`) y todos los módulos comunes que importan. Con ellos se verificaron las rutas de la matriz de trazabilidad (ver `specs/features/0005-trazabilidad-sunat-ubl/spec.md`, sección 17).
